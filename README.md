# Bank Loan Analysis Dashboard

## Project Overview
This project analyzes bank loan application data using Power BI. It helps understand loan approvals, rejections, applicant details, and credit history.

## Tools Used
- Power BI
- Power Query
- DAX

## Key Insights
- Total loan applications
- Approved and rejected loans
- Loan approval rate
- Applications by gender and education
- Credit history analysis
- Property area and marital status analysis

## Dashboard Features
- KPI cards for important metrics
- Interactive slicers for filtering data
- Charts to compare loan application patterns

## Dataset
The project uses a bank loan application dataset containing applicant details, income, loan amount, credit history, and loan status.
